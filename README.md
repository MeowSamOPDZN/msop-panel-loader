# MSOP Panel — Script Hub

Roblox script hub loader. Drop it in your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/MeowSamOPDZN/msop-panel-loader/main/.lua"))()
```

- Auto-launches the matching script when you join a supported game.
- Otherwise opens the panel — pick any game script to launch it anyway.
- Press **LeftControl** to show / hide the panel.

Website: https://mnaii.vercel.app
